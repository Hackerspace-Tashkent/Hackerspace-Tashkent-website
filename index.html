About the Community

Hackerspace Tashkent is a community for people interested in technology, open source, electronics, programming, DIY projects, and practical learning.

We share what we know and what we are learning. The first thing we made is this learning program: it works, you can start today, and nobody has done it yet.

What we have now

17 topics, 143 automatic checks

Linux, files, Git, Bash, automation, processes, network, GitHub, Actions, Pages, HTTP API.

Four languages

English, Russian, Uzbek in Latin script, Uzbek in Cyrillic. The code is identical; the explanations are translated.

Free, in the browser

GitHub Codespaces. Nothing to install, no local setup, works on a phone browser.

Security track

Five topics: what a server sees, secrets in code, passwords and hashes, HTTPS, SQL injection. Your own machine only.

We just started. No members, no meetings, no hardware yet — only the program, which already works.
